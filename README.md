# Doba (Android)

Automatyczne śledzenie czasu w stylu iOS-owej aplikacji Life Cycle: pierścień dnia, oś czasu, statystyki tygodniowe, miesięczne i roczne oraz mapa miejsc.

- Pobyty w miejscach wykrywane z lokalizacji (usługa pierwszoplanowa, Fused Location)
- Chodzenie, bieganie, rower i jazda z Activity Recognition
- Sen z Health Connect albo z nocnej przerwy w używaniu telefonu
- Ręczne dodawanie i poprawianie wpisów, własne kategorie, eksport CSV

APK buduje GitHub Actions — gotowy plik jest w zakładce **Releases**.
